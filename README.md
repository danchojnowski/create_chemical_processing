# Create: Chemical Processing

A chemical factory mod for Minecraft 1.21.1, NeoForge 21.1.262, and Create 6.0.10.

Requires JDK 21. Run `./gradlew build` to build the mod, `./gradlew runClient` to launch a development client, or `./gradlew runServer` to launch a development server. The built JAR is placed in `build/libs/`.

## Chemical centrifuge (early development)

The planned centrifuge accepts one solid or fluid input through a top port and produces up to two solid and two fluid outputs through bottom ports. It will use a bearing-driven multiblock with a square interior 1, 2, or 3 blocks wide and any positive height.

Right-click the Centrifuge Block with an empty hand to check and assemble the structure. A message reports success or an invalid structure. Right-clicking with a Create wrench also briefly marks invalid positions with red particles for the closest matching size and bearing. If no bearing is found, the intended height cannot be determined and no positions are marked. The assembled state is saved and checked about once per second; damage to the structure clears it. Neighboring chunks must be loaded for assembly, and an assembled structure retains its state while those chunks are unavailable. Ports, recipes, processing, and bearing rotation are not yet implemented. The current provisional geometry uses a one-block-thick wall, a bottom-slab floor with a bearing in its center, a roof with stairs around the outer edge and wall material in the middle, and a Centrifuge Block above the roof at the same horizontal position as the bearing (north-west of center for even widths). The block has a stepped cone model and is available in the Functional Blocks creative tab. The bearing replaces a slab at the center of the floor (north-west of center for an even-width interior). The interior must be air. Height is bounded by the world's build limits, and unloaded chunks cause validation to fail. Stair orientation and bearing direction are not checked yet.

Accepted wall, floor, and roof blocks are configurable with the `create_chemical_processing:centrifuge_walls`, `centrifuge_floor_slabs`, and `centrifuge_roof_stairs` block tags in a datapack. Defaults are iron block, copper block, and glass for walls; smooth stone slabs for floors; and stone brick and deepslate stairs for roof edges. Floor entries must be slabs placed in the bottom half, and roof edge entries must be stairs; roof centers use the wall tag.

The drive uses an upward-facing Create mechanical bearing with a vertical Create shaft directly below it. An assembled centrifuge is marked running when the bearing speed reaches the configured minimum in either direction; a stopped or overstressed drive does not meet the requirement. Set `[centrifuge] minimumRpm` in the world server config `serverconfig/create_chemical_processing-server.toml` (default 128, range 1–256). Speed is checked about once per second. Running is currently only a state indicator: processing and a dedicated bearing/contraption integration are not implemented, and Create’s bearing may assemble and move the shell when powered.
